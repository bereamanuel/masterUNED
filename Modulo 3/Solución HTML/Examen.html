1.2 Estimar modelo que relaciones el precio de freebny con las ventas de freeny

Es decir, tenemos que estimar los parámetros \(\beta_0, \beta_1\)de la siguiente ecuación:

\[y = \beta_0 + \beta_1 x + \epsilon\]

Donde y es la variable objetivo, x la variable price.index, \(\beta_0\) es la ordenada en el origen, \(\beta_1\) es la pendiente, y \(\epsilon\) es el error.

Para estimar el modelo de regresión simple, utilizaremos la función lm, que nos permite ajustar un modelo lineal. En este caso, la variable dependiente es y, y la variable independiente es price.index.

modelo1 <- lm(y ~ price.index, data = freeny)
summary(modelo1)

Podemos ver como el modelo se ha ajustado bien, ya que el valor de R cuadrado es 0.9791, lo que significa que el 97.9% de la variabilidad de la variable dependiente es explicada por la variable independiente. Además, el p-valor es muy bajo, lo que significa que la variable independiente es significativa.

1.3 Obtener intervalos de confianza de los parámetros

Para obtener los intervalos de confianza de los parámetros, utilizaremos la función confint, que nos permite obtener los intervalos de confianza de los parámetros del modelo. En este caso, queremos obtener los intervalos de confianza del 95% de los parámetros del modelo.

intervalos_conf <- confint(modelo1, level = 0.95)
round(intervalos_conf, 3)
##              2.5 % 97.5 %
## (Intercept) 19.324 20.348
## price.index -2.456 -2.228

Podemos interpretar la tabla de la siguiente manera: - Intercept: El intervalo de confianza del 95% para el parámetro \(\beta_0\) es (19.324, 20.348). Esto significa que con un 95% de confianza, el valor real del parámetro \(\beta_0\) estará entre 19.324 y 20.348 - price.index: El intervalo de confianza del 95% para el parámetro \(\beta_1\) es (-2.456, -2.228). Esto significa que con un 95% de confianza, el valor real del parámetro \(\beta_1\) estará entre -2.456 y -2.228

Esto quiere decir que la relación entre la variable dependiente y la variable independiente es significativa, ya que el intervalo de confianza no incluye el 0. Además, que la relacción es negativa, pero eso ya lo pudimos observar en la matriz de covarianzas y correlaciones.

1.4 Evaluar coeficiente de determinación y residuos

Para obtener \(R^2\) y los residuos del modelo, utilizaremos las funciones summary y residuals.

r_sq1 <- summary(modelo1)$r.squared
res1 <- residuals(modelo1)
print(paste0("Tenemos un R cuadrado de: ", r_sq1))
## [1] "Tenemos un R cuadrado de: 0.979133660021951"

Como ya hemos explicado, este valor al ser muy cercano a 1, significa que el modelo se ajusta muy bien a los datos.

Los residuos deberían cumplir con estos supuestos básicos: - Media cercana a cero. - Distribución normal. - Varianza constante (homocedasticidad). - Independencia (especialmente importante en series temporales).

Para analizar grafícamente estos puntos podemos utilizar la funcion plot, que nos permite ver la distribución de los residuos, y la función acf, que nos permite ver la autocorrelación de los residuos. Aunque también podemos utilizar test estadísticos como el test de Shapiro y Durbin-Watson, que nos permite ver si existe normalidad o hay autocorrelación en los residuos respectivamente.

par(mfrow = c(2, 2))
plot(modelo1)

Podemos ver en el Q-Q plot que los residuos no parecen ajustarse a un normal, vamos a comprobar con el test de Shapiro-Wilk si podemos rechazar la hipótesis nula de que los residuos siguen una distribución normal.

print(paste0("Los residuos tienen media: ",round(mean(res1),4)))
## [1] "Los residuos tienen media: 0"
shapiro.test(res1)
## 
##  Shapiro-Wilk normality test
## 
## data:  res1
## W = 0.94298, p-value = 0.04781

Vemos que el \(p-value\) es \(0.04781\) que es menor a \(0.05\), por lo que podemos rechazar la hipótesis nula de que los residuos siguen una distribución normal. Como nuestro problema tiene una cantidad de observaciones elevada, debido al teorema central del límite, podemos dejar pasar por alto este supuesto.

Vamos a comprobar si existe heterocedasticidad en los residuos, es decir, si la varianza de los residuos es constante. Para ello, utilizaremos el test de Breusch-Pagan, que nos permite ver si la varianza de los residuos es constante.

bptest(modelo1)
## 
##  studentized Breusch-Pagan test
## 
## data:  modelo1
## BP = 1.1962, df = 1, p-value = 0.2741

El \(p-value\) es \(0.2741\), por lo que no podemos rechazar la hipótesis nula de que la varianza de los residuos es constante. Por lo que podemos decir que no hay heterocedasticidad en los residuos.

Para comprobar si los residuos son independientes, utilizaremos el test de Durbin-Watson, que nos permite ver si hay autocorrelación en los residuos.

durbinWatsonTest(modelo1)
##  lag Autocorrelation D-W Statistic p-value
##    1       0.8218003     0.3473076       0
##  Alternative hypothesis: rho != 0

El valor de Durbin-Watson es \(0.3473076\), que está lejos de \(2\), por lo que podemos decir que los residuos estan correlacionados, esto incumple uno de los supuestos básicos del modelo. En nuestro conjunto de datos esto no sorprende, ya que los valores de ventas de un trimestre dependen directamente del trimestre anterior. Esto indica que aunque el \(R^2\) sea alto, el modelo no es el más adecuado para predecir las ventas o que debemos realizar transformaciones en las variables.

1.5 Realizar el contraste de si la relación entre precios y ventas de freeny es negativa con un nivel de significación del 0.05

Para realizar el contraste de si la relación entre precios y ventas de freeny es negativa, utilizaremos el test de hipótesis. La hipótesis nula es que la relación entre precios y ventas de freeny es positiva, y la hipótesis alternativa es que la relación entre precios y ventas de freeny es negativa.

Es decir \(H_0 : \beta_{price.index}\geq 0\) y \(H_1 : \beta_{price.index}< 0\) , si el $p-value < 0.05 $ podemos rechazar la hipotesis nula y aceptar la hipotesis alternativa.

2.5 A la vista de las variables explicativas cree que sería más adecuado estimar el modelo utilizando la regresión ridge o el mínimo cuadrado ordinario. En caso afirmativo estime el modelo y analice sus resultados.

El modelo ridge es un modelo de regresión lineal que utiliza la regularización L2, que nos permite reducir la complejidad del modelo y evitar el sobreajuste. Es adeacuado cuando tenemos multicolinealidad en las variables explicativas, ya que reduce la varianza de los coeficientes. Para ver si es conveniente utilizar este modelo, podemos comprobar la multicolinealidad de las variables explicativas utilizando la función vif, que nos permite ver el factor de inflación de la varianza de las variables explicativas.

vif(modelo_glm)
##      price.index     income.level market.potential 
##         53.71126         25.10082        104.22550

Como estamos obteniendo valores muy altos de VIF, podemos decir que hay multicolinealidad en las variables explicativas, por lo que sería más adecuado estimar el modelo utilizando la regresión ridge. Para estimar el modelo utilizando la regresión ridge, utilizaremos la función glmnet, que nos permite ajustar un modelo de regresión ridge.

X <- model.matrix(y ~ price.index + income.level + market.potential, data=freeny)[,-1]
